# phishing-awareness-checklist.
Student-friendly phishing awareness checklist: red-flags guide, response checklist, incident report template and a simple URL red-flag checker.
## Why this project?

Phishing is one of the most common ways attackers steal credentials and deliver malware, because it targets people rather than technology. This toolkit gives users clear guidance, gives a Security Operations Centre (SOC) a consistent way to collect reports, and demonstrates good version-control practice on a security resource.

## What's inside

| Resource | Purpose | Location |
|----------|---------|----------|
| Red-flags guide | Explains phishing types and eight warning signs | `docs/` |
| Response checklist | Actions before and after interacting with a message | `checklists/` |
| Incident report template | Standard form for reporting to the SOC | `templates/` |
| URL red-flag checker | Python script that scores a link for phishing warning signs | `scripts/` |

## Status

Work in progress. Resources are being added one commit at a time.
