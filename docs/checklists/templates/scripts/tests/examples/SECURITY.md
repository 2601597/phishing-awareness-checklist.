# Security Policy

## Scope

This repository contains **educational material only**: guides, checklists, templates and a small script that analyses the text of URLs. It does not store real incident data, credentials or personal information.

## Please do not commit

- Passwords, API keys, tokens or private keys
- Real phishing emails (`.eml` / `.msg`) or live malicious links
- Real names, student numbers or contact details of victims

Use fictional data and defanged links (`hxxps://example[.]com`) in any example. The `.gitignore` blocks the most common risky file types, but it is not a substitute for checking your changes before you commit.

## Reporting a problem with this repository

If you find a mistake in the guidance, or accidentally spot sensitive data in the repository, open a private report through the repository's **Security** tab (Report a vulnerability), or contact the maintainer directly instead of posting details in a public issue.
