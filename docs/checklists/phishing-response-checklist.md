# Phishing Response Checklist

Use this checklist when you receive a suspicious message, or when you think you may have interacted with one. Tick each box as you go.

## 1. Before you click

- [ ] Is the message unexpected, urgent or threatening?
- [ ] Does the sender's real address match the organisation it claims to be from?
- [ ] Did I hover over every link and check where it really leads?
- [ ] Is it asking for a password, PIN, OTP, ID number or payment?
- [ ] Is there an attachment I was not expecting?

> If you answered **yes** to any of these, do not click. Go to section 5 (Report).

## 2. If you clicked a link but entered nothing

- [ ] Close the browser tab immediately.
- [ ] Run a full antivirus / endpoint scan.
- [ ] Clear the browser cache and downloads from that session.
- [ ] Report the message (section 5).

## 3. If you entered a password or other credentials

- [ ] Change the password on that account **now**, from a trusted device.
- [ ] Change it anywhere else you reused it.
- [ ] Sign out of all active sessions and review recent sign-in activity.
- [ ] Make sure MFA is enabled; re-register your authenticator if needed.
- [ ] Tell the SOC / IT helpdesk straight away (section 5).

## 4. If you opened an attachment or installed something

- [ ] Disconnect the device from Wi-Fi and unplug network cables.
- [ ] Do **not** switch the device off unless instructed; it may hold evidence.
- [ ] Contact the SOC / IT helpdesk by phone.
- [ ] Do not log in to any account from that device until it has been cleaned.

## 5. Report

- [ ] Do not forward the message to colleagues or friends.
- [ ] Fill in the [incident report template](../templates/phishing-incident-report-template.md).
- [ ] Send it to the SOC / IT helpdesk **within 24 hours** (sooner if you clicked or entered data).
- [ ] Delete the original message after the SOC confirms receipt.

## 6. Afterwards

- [ ] Watch your accounts for unusual activity over the next few weeks.
- [ ] Warn people who may have received the same message, through official channels.
- [ ] Note what gave the message away so you can spot it next time.
